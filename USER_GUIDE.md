## Getting Started

### First Launch

When you first open LeadFlow, you'll see:
- A welcome banner explaining the dashboard's purpose
- Your key performance metrics at a glance
- Interactive charts showing your sales data
- A calendar for managing meetings
- Recent activities from your team

### Customizing Your Experience

**Theme Selection**
- Click the sun/moon icon in the header to toggle between light and dark mode
- Your preference is automatically saved and persists across sessions

**Dismissing the Welcome Banner**
- Click the X button in the top-right corner of the welcome message
- This preference is saved, and the banner won't appear again

## Dashboard Overview

### Header Bar
Located at the top of the screen with the following controls:

- **Logo**: LeadFlow branding with animated icon
- **Theme Toggle**: Switch between dark and light modes
- **Refresh Button**: Reload all dashboard data (shows loading animation)
- **Notes Button**: Open your notes manager
- **Export Button**: Download data as CSV or JSON
- **Mobile Menu**: On smaller screens, access all controls via hamburger menu

### Stats Cards (Top Section)
Four key metrics displayed prominently:

1. **Total Leads** (Blue)
   - Shows total number of leads in your pipeline
   - Displays percentage change from last month

2. **Calls Made** (Green)
   - Total calls completed by your team
   - Shows weekly growth percentage

3. **Meetings Scheduled** (Amber)
   - Number of upcoming meetings
   - Displays monthly growth

4. **Conversion Rate** (Purple)
   - Percentage of leads converting to customers
   - Shows comparison to last month

*Tip: Hover over cards to see them lift with a subtle animation*

## Features Guide

### 📊 Charts & Analytics

#### Lead Activity Chart
**Purpose**: Track active leads and completed calls over time

**How to Use**:
1. View the combined area (active leads) and bar chart (calls completed)
2. Click Week/Month/Year buttons to change the time period
3. Hover over data points to see exact values
4. The blue area shows lead volume trends
5. Green bars indicate call completion rates

**Insights**:
- Compare lead activity patterns across different periods
- Identify peak calling days or months
- Spot trends in lead engagement

#### Conversion Rate Chart
**Purpose**: Monitor how your conversion rate changes over time

**How to Use**:
1. View the amber line showing conversion percentage
2. Switch between Week/Month/Year views
3. Hover over points to see exact conversion rates
4. Look for upward or downward trends

**Insights**:
- Identify which time periods have the best conversion rates
- Spot seasonal patterns
- Track improvement over time

#### Lead Source Distribution
**Purpose**: Understand where your leads are coming from

**How to Use**:
1. View the colorful donut chart
2. Change time period to see how sources vary
3. Hover over segments to see exact numbers
4. Review the legend at the bottom

**Lead Sources**:
- **Website** (Blue): Direct website inquiries
- **Referrals** (Green): Word-of-mouth recommendations
- **Social Media** (Amber): Social platform leads
- **Email Campaign** (Purple): Email marketing results
- **Direct** (Red): Direct contact leads

### 📅 Meeting Calendar

#### Viewing Meetings
1. Current month is displayed by default
2. Today's date is highlighted in blue
3. Days with meetings show a small dot indicator
4. Click any date to view scheduled meetings for that day

#### Navigating the Calendar
- **Previous Month**: Click the left arrow
- **Next Month**: Click the right arrow
- **Clear Selection**: Click the X button when viewing a date's meetings

#### Meeting Details
When you select a date with meetings, you'll see:
- Meeting title
- Client name
- Time and duration
- Meeting type (Video call 🎥 or Phone call 📞)

#### Adding a New Meeting
1. Click the + button in the calendar header
2. Fill out the meeting form:
   - **Title**: Brief description (e.g., "Product Demo")
   - **Client Name**: Company or contact name
   - **Date**: Pick from date picker
   - **Time**: Select meeting time
   - **Duration**: Choose from preset durations (15 min to 2 hours)
   - **Type**: Select Video or Phone call
3. Click "Schedule Meeting" to save
4. The meeting appears immediately on the calendar

### 📋 Recent Activities

**Activity Timeline**
A chronological feed of recent team activities with:
- Color-coded icons for different activity types
- Activity descriptions
- Associated lead/company names
- Time stamps (e.g., "2 hours ago")
- Priority badges (High/Medium/Low)

**Activity Types**:
- 📞 **Calls**: Phone conversations with leads
- 📧 **Emails**: Email correspondence
- 📅 **Meetings**: Completed or scheduled meetings
- ✅ **Deals**: Closed deals with revenue amounts
- 👤 **New Leads**: Recently added leads
- 📄 **Proposals**: Sent proposals

**Priority Indicators**:
- 🔴 **High**: Urgent items requiring immediate attention
- 🟡 **Medium**: Important but not urgent
- ⚪ **Low**: Standard priority items

### 🔔 Lead Alerts

**Viewing Alerts**
- Alert count badge shows total number of active alerts
- Color-coded left border indicates alert type:
  - **Blue**: Informational messages
  - **Green**: Success notifications
  - **Amber**: Warnings requiring attention
  - **Red**: Critical errors

**Managing Alerts**
1. Hover over an alert to reveal the delete button
2. Click X to dismiss an alert
3. Deleted alerts animate smoothly out of view

**Creating Custom Alerts**
1. Click the + button in the alerts header
2. Select alert type from dropdown:
   - Info
   - Success
   - Warning
   - Error
3. Enter your alert message
4. Click "Add Alert" to save
5. Click "Cancel" to discard

**Best Practices**:
- Use warnings for leads that need follow-up
- Create success alerts for closed deals
- Set info alerts for upcoming deadlines
- Error alerts for issues requiring immediate attention

### 📝 Notes Manager

**Accessing Notes**
- Click the notes icon in the header
- Modal opens with all your saved notes

**Creating Notes**
1. Type your note in the text area
2. Press Enter or click "Add Note"
3. Notes are automatically timestamped
4. Saved instantly to your browser

**Managing Notes**
- Hover over a note to see the delete button
- Click the trash icon to remove a note
- Notes are sorted with newest first
- Each note shows how long ago it was created

**Use Cases**:
- Quick reminders about leads
- Follow-up actions needed
- Meeting preparation notes
- Client preferences or details

### 💾 Exporting Data

**Export Options**
1. Click the download icon in the header
2. Select format:
   - **CSV**: Spreadsheet-compatible format
   - **JSON**: Structured data format

**What Gets Exported**:
- All key stats (leads, calls, meetings, conversion rate)
- Notes collection
- Active alerts
- Scheduled meetings
- Export date/time stamp

**File Naming**:
Files are automatically named: `leadflow-data-YYYY-MM-DD.csv/json`

## Troubleshooting

### Common Issues

**Data Not Refreshing**
- Click the refresh button in the header
- Wait for the spinning animation to complete
- If issues persist, refresh the browser page

**Theme Not Saving**
- Check browser's localStorage is enabled
- Try clearing browser cache
- Re-select your preferred theme

**Charts Not Displaying**
- Ensure JavaScript is enabled
- Try a different browser
- Check your internet connection
- Refresh the page

**Modals Not Opening**
- Check for browser popup blockers
- Refresh the page
- Try a different browser

**Mobile Menu Issues**
- Ensure device width is below 768px
- Try rotating device orientation
- Refresh the page

### Browser Compatibility

**Recommended Browsers**:
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

**Minimum Requirements**:
- JavaScript enabled
- LocalStorage enabled
- Modern CSS support (Grid, Flexbox)
- SVG support

### Data Persistence

**What's Saved**:
- Theme preference (light/dark)
- Notes (all content)
- Welcome banner dismissal
- Stored in browser's localStorage

**What's NOT Saved**:
- Chart time periods (resets to month)
- Selected calendar dates
- Open modals
- Alert creation form state

**Clearing Data**:
To reset everything:
1. Open browser DevTools (F12)
2. Go to Application/Storage tab
3. Clear localStorage for this site
4. Refresh the page
