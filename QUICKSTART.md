# LeadFlow - Quick Start Guide

Get up and running with LeadFlow in 5 minutes! 🚀

## 📦 Installation

### Option 1: Run Locally (Development)

1. **Open Terminal/Command Prompt** and navigate to the project folder:
   ```bash
   cd leadflow
   ```

2. **Install Dependencies** (first time only):
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Open Your Browser**:
   - Go to `http://localhost:5173` (or the port shown in terminal)
   - The dashboard loads automatically!

### Option 2: Production Build

1. **Build the Project**:
   ```bash
   npm run build
   ```

2. **Preview Production Build**:
   ```bash
   npm run preview
   ```

3. **Deploy**:
   - Upload the `dist` folder to any static hosting service
   - Services: Vercel, Netlify, GitHub Pages, AWS S3, etc.

## 🎯 First Steps

### 1. Choose Your Theme (1 min)
- Click the **sun/moon icon** in the top-right corner
- Switch between Light and Dark mode
- Your choice is saved automatically!

### 2. Explore the Dashboard (2 min)
- **Top Stats**: View your key metrics at a glance
- **Charts**: Click Week/Month/Year to see different time periods
- **Calendar**: Click any date to see scheduled meetings
- **Activities**: Scroll through recent team activities

### 3. Add Your First Meeting (1 min)
1. Click the **+ button** on the Meeting Calendar
2. Fill in:
   - Meeting title (e.g., "Product Demo")
   - Client name (e.g., "Acme Corp")
   - Date and time
   - Duration and type (Video/Phone)
3. Click **Schedule Meeting**
4. See it appear on the calendar!

### 4. Create a Note (30 sec)
1. Click the **notes icon** in the header
2. Type your note (e.g., "Follow up with lead tomorrow")
3. Press Enter or click **Add Note**
4. Your note is saved instantly!

### 5. Set Up an Alert (30 sec)
1. Scroll to the **Lead Alerts** section
2. Click the **+ button**
3. Choose alert type and write your message
4. Click **Add Alert**

## ⚡ Quick Feature Reference

### Header Controls
| Icon | Action | Shortcut |
|------|--------|----------|
| 🌙/☀️ | Toggle dark/light mode | - |
| 🔄 | Refresh dashboard data | - |
| 📝 | Open notes manager | - |
| ⬇️ | Export data (CSV/JSON) | - |
| ☰ | Mobile menu (on small screens) | - |

### Chart Time Periods
- **Week**: Last 7 days of data
- **Month**: Last 30 days of data  
- **Year**: Last 12 months of data

Click the buttons on any chart to switch periods!

### Activity Types
- 📞 **Call**: Phone conversations
- 📧 **Email**: Email correspondence
- 📅 **Meeting**: Scheduled/completed meetings
- ✅ **Deal**: Closed deals (shows $$ amount)
- 👤 **Lead**: New leads added
- 📄 **Proposal**: Proposals sent

### Priority Badges
- 🔴 **High**: Urgent - act immediately
- 🟡 **Medium**: Important but not urgent
- ⚪ **Low**: Standard priority

## 🔧 Common Tasks

### Export Your Data
1. Click the **download icon** in header
2. Choose **CSV** (for Excel) or **JSON** (for code)
3. File downloads automatically
4. Opens in Excel/text editor

### Manage Notes
- **Add**: Click notes icon → type → press Enter
- **Delete**: Hover over note → click trash icon
- **View**: Click notes icon anytime

### Navigate Calendar
- **Previous Month**: Click left arrow ←
- **Next Month**: Click right arrow →
- **View Meetings**: Click any date with a dot
- **Clear Selection**: Click X when viewing meetings

### Customize Alerts
- **Info** (Blue): General information
- **Success** (Green): Achievements and wins
- **Warning** (Yellow): Items needing attention
- **Error** (Red): Critical issues

## 🐛 Troubleshooting

### Dashboard Not Loading?
- Check internet connection
- Refresh the page (F5)
- Clear browser cache
- Try a different browser

### Charts Not Showing?
- Enable JavaScript in browser
- Disable ad blockers temporarily
- Update to latest browser version

### Data Not Saving?
- Check if cookies/localStorage is enabled
- Try a different browser
- Clear browser data and try again

### Mobile Issues?
- Update mobile browser
- Try desktop mode
- Rotate device orientation
